# RobocodeHorror

## Версія Unity
6.3 LTS, Universal 3D

## Швидкий старт
1. Встановіть Git і Unity потрібної версії.
2. `git clone https://github.com/mariannyx/RobocodeHorror.git`
3. Unity Hub → Add project from disk → оберіть папку.

## Правила
- Не пушимо в `main`, лише через Pull Request (рев'юер: пан Викладач).
- Одну сцену одночасно редагує одна людина, повідомте в чаті.
- Комітимо `.meta` файли. Не комітимо `Library`, `Temp`, `Logs`, `Builds`.
- Файли більше ~25 МБ лише після узгодження з лідом.
- Проблеми з Git: пишіть у чат, не лагодьте самотужки.
